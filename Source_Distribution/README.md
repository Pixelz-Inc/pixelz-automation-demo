# Pixelz Automation Demo App

A "Living Documentation" application for the Pixelz Automation API.

## Features
- Real-time JSON Request/Response visualization
- Asynchronous workflow polling with status updates
- Interactive API Lab for various methods (Remove Background, Create Mask, etc.)
- Multi-token support and auto-refresh logic
- Webhook signature verification tool
- Light/Dark mode support

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Extract the source code.
2. Run `npm install`.
3. Obtain a Pixelz API Token.

### Development
```bash
npm run dev
```

### Build
```bash
npm run build:win
```
